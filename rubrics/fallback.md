## Lab requirements

The following requirements describe the necessary deliverables for the Writing Policies Lab.

| Criteria                                                                                                                                                                                                                                   | Points |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| The **Acceptable Use Policy** document is formatted in a clear manner.                                                                                                                                                                     | 15     |
| The **Acceptable Use Policy** document uses clear and professional language.                                                                                                                                                               | 15     |
| The **Acceptable Use Policy** document uses language that is specific and direct.                                                                                                                                                          | 10     |
| The **Acceptable Use Policy** document provides examples to clarify concepts.                                                                                                                                                              | 10     |
| The **Acceptable Use Policy** document specifies acceptable internet and email use.                                                                                                                                                        | 10     |
| The **Acceptable Use Policy** document specifies acceptable social media conduct.                                                                                                                                                          | 10     |
| The **Acceptable Use Policy** document specifies data access, storage, and sharing requirements.                                                                                                                                           | 10     |
| The **Acceptable Use Policy** document specifies at least two of the following: acceptable password and authentication practices, device and network security requirements, device and network security, or remote work and BYOD policies. | 20     |
| **Total possible points**                                                                                                                                                                                                                  | 100    |
